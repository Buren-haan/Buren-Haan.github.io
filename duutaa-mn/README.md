# Дуутаа · MN

Монгол дууг Heardle/Songless загвараар таах тоглоом. Дуу 0.1с → 0.5с → 2с → 8с → 15с
гэсэн дараалалтай хэсгүүдээр тоглогдож, хэрэглэгч аль болох эрт таавал илүү оноо авна
(5 / 4 / 3 / 2 / 1). Гурван горим бий:

- **Ганцаараа** — өөрөө сорих
- **Найзуудтайгаа (нэг утсаар)** — ижил өрөөнд, нэг утсыг дамжуулан тоглох, тоглоом
  даалгаварлагч (та) хэн эхэлж таасныг гараар тэмдэглэнэ
- **Онлайн өрөө** — хүн бүр өөрийн утаснаасаа кодоор нэгдэж, ижил дуунуудыг тус тусдаа
  таагаад оноогоороо өрсөлддөг

## Хамгийн чухал: аудио эх сурвалж тухайд

Тоглоом mp3 файл ХАДГАЛДАГГҮЙ — GitHub дээр зохиогчийн эрхтэй дууны файл байршуулах
эрсдэлтэй тул. Оронд нь **YouTube-г л тоглуулагч болгон ашигладаг**: `songs.js` дотор
YouTube видеоны ID болон тухайн дууны хамгийн танигдахуйц хэсэг хэдэн секундээс
эхэлдгийг бичнэ, тоглоомын үед тухайн секундээс тодорхой хугацаагаар (0.1с гэх мэт)
тоглуулаад зогсооно. Иймд аудио бол зохиогчийн эрхийн эзэн (YouTube дээрх сувгууд)-д
харьяалагдсан хэвээр байна.

## Дуу нэмэх

`songs.js` файлыг нээгээд массивт объект нэмнэ:

```js
{
  id: "unique_id",                 // өвөрмөц, зайгүй
  title: "Дууны нэр",
  artist: "Дуучин/хамтлаг",
  youtubeId: "dQw4w9WgXcQ",        // YouTube линкийн ?v= -ийн ард орсон 11 тэмдэгт
  start: 35,                       // хамгийн танигдахуйц хэсэг эхэлдэг секунд
  answers: ["өөр бичих хувилбар", "латинаар", "товчлол"]
}
```

`start`-ыг зөв сонгохын тулд дууг сонсоод хамгийн танигдахуйц мөч (ихэвчлэн эхний
хос, эсвэл гол ая эхлэх газар)-ийг олоод секундийг нь бич. Зөвхөн Монгол зохиолын
дуу нэмнэ.

## Локал дээр турших

Ямар нэгэн build хэрэггүй — цэвэр статик HTML/CSS/JS. Хамгийн энгийн нь:

```bash
cd duutaa-mn
python3 -m http.server 8000
# эсвэл: npx serve
```

`http://localhost:8000` дээр нээнэ. (`file://`-ээр шууд нээвэл YouTube API ажиллахгүй,
localhost/https шаардлагатай.)

## GitHub Pages дээр байршуулах (Buren-haan.github.io)

1. Энэ бүх файлыг `Buren-haan/Buren-haan.github.io` repo-руу хуулна (эсвэл дэд
   хавтас/тусдаа repo болгон project pages болгож болно).
2. Repo-гийн **Settings → Pages** хэсэгт Source-г `main` branch, `/ (root)`
   болгож сонгоно.
3. Хэдэн минутын дараа `https://buren-haan.github.io/` дээр (эсвэл project repo бол
   `https://buren-haan.github.io/<repo-name>/`) идэвхжинэ.

## Онлайн өрөө горимыг идэвхжүүлэх (Firebase)

Онлайн горим Firebase Realtime Database ашиглана — үнэгүй Spark төлөвлөгөө хангалттай.

1. https://console.firebase.google.com → **Add project** → нэр өгөөд үүсгэнэ
   (Google Analytics-г идэвхгүй болгож болно).
2. Зүүн цэснээс **Build → Realtime Database → Create Database**. Байршил сонгоод
   (жишээ нь `asia-southeast1`), эхэндээ **Test mode**-оор эхэлж болно (30 хоногийн
   дараа хаагдана — доор бодит Rules-г бичсэн байгаа).
3. Төслийн тохиргоо ️ **Project settings → General → Your apps → Web app (</>)**-г
   дараад бүртгүүлж, өгөгдсөн `firebaseConfig` объектыг хуулна.
4. `firebase-config.sample.js` файлыг хуулж `firebase-config.js` нэрээр хадгалаад,
   4-р алхамд авсан утгуудаа тавь.
5. Realtime Database → **Rules** хэсэгт дараах байдлаар тохируулж болно (найзуудын
   дунд тоглох жижиг тоглоом тул нээлттэй бичих/унших зөвшөөрөл өгсөн — том хэмжээний
   public ашиглалтад тохиромжгүйг анхаарна уу):

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

`firebase-config.js` файлыг Git-д commit хийхээс сэргийлж `.gitignore`-д
`firebase-config.js` гэж нэмж болно — гэхдээ тэгвэл GitHub Pages дээр энэ файл
байхгүй тул онлайн горим ажиллахгүй болно. Хувийн repo эсвэл Actions secret ашиглаж
build хийх боломжтой ч, энгийн хэрэглээнд шууд commit хийгээд явуулж болно (Realtime
Database Rules нь жинхэнэ хамгаалалт учраас).

## Онооны систем

| Хэсэг | Урт | Оноо |
|---|---|---|
| 1 | 0.1с | 5 |
| 2 | 0.5с | 4 |
| 3 | 2с | 3 |
| 4 | 8с | 2 |
| 5 | 15с | 1 |

`app.js` дотор `DURATIONS` болон `POINTS` массивуудыг өөрчилж тохиргоог өөрчилж
болно.

## Мэдэгдэж буй хязгаарлалт

- 0.1с шиг маш богино хэсгийг `setTimeout`-оор зогсоодог тул browser/сүлжээнээс
  шалтгаалж бага зэрэг өөр өөр байж болно — тоглоомын зорилгод хангалттай.
- YouTube видео түр хугацаанд устгагдвал/хувийн болговол тухайн дуу тоглохгүй.
- Онлайн горим нэвтрэлт (auth) ашигладаггүй тул Rules нээлттэй — жижиг, найзуудын
  дундах тоглоомд зориулагдсан.
